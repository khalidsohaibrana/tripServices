## 4. Brand Assets

Please provide final, approved files. PNG is preferred for logos and icons. The app icon should be square and at least `1024x1024` pixels.

| Asset | Required filename or format | Provided? |
| --- | --- | --- |
| Main app logo | `logo.png` or `logo.jpg` | Yes / No |
| App icon | Square PNG, at least `1024x1024` | Yes / No |
| Invoice logo | PNG or JPG | Yes / No |
| Home screen background | JPG or PNG | Yes / No |
| Launch or splash image | PNG or JPG | Yes / No |
| Light-mode logo variant | Optional | Yes / No |
| Dark-mode logo variant | Optional | Yes / No |

For each file, confirm:

- The client owns or has permission to use it.
- The file is final and approved for production.
- The logo has sufficient contrast on its intended background.
- The app icon does not contain important artwork too close to the edges.
